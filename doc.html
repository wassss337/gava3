🛠️ Установка

git clone https://github.com/wassss337/gava3.git
cd gava3
.\install_gava.bat

gava start app.gava — запустить скрипт

📦 Система модулей

Файл http.glc (JSON-манифест):

{
   "name": "http",
   "direct": "http/",
   "main": "http/main.cpp"
}

import http; — компилирует C++ в фоне и загружает в память.

⚡ Импорт C++

// __init__.gava
import cpp api.main;
import cpp socket;

Крупные C++ файлы компилируются на несколько миллисекунд раньше.

🎨 VS Code Extension

Файл gava-extension.vsix — установка через Extensions → Install from VSIX.

💡 Пример кода

import http;
import json;

async function fetchData() {
    let response = await http.get("https://api.example.com");
    let data = json.parse(response);
    print(data);
}

fetchData();
